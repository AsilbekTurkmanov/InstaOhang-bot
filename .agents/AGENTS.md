# Workspace Rules

1. **Auto-Run & GitHub Prompt Workflow**:
   - Har bir vazifani bajarib tugatgandan so'ng, botni avtomatik ravishda fonda ishga tushirish (`run` qilish).
   - Vazifa to'liq tugatilgach, foydalanuvchiga: **"GitHub'ga joylaymi?"** deb so'rash.
   - Foydalanuvchi "ha" yoki rozilik bildirsa, git commit qilib GitHub repository'ga push qilish.
